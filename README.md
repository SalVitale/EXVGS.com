# EXVGS website

A simple black landing page. No installation or build step is needed.

- Repository: https://github.com/SalVitale/EXVGS.com
- GitHub Pages: https://salvitale.github.io/EXVGS.com/
- Desktop folder: `EXVGS.com`

This repository contains only the website. The EXVGS game source is a separate repository.

Edit `index.html` for text and links, `style.css` for appearance, and `favicon.svg` for the browser icon.

## Publish changes with GitHub Desktop

1. Select **EXVGS.com** in the **Current repository** menu.
2. Review the changed files and enter a short summary.
3. Click **Commit to main**, then **Push origin**.
4. GitHub Pages publishes the `main` branch from the repository root. Allow a few minutes for updates.

Use **Fetch origin** and **Pull origin** before editing if changes were made on another computer or GitHub.

## Custom domain

The initial site uses the GitHub Pages address above. To use `exvgs.com`, configure the custom domain under the repository's **Settings → Pages**, then point the domain's DNS at GitHub Pages using GitHub's current instructions:
https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site

Once the domain is connected, update the link to this site in the Digiflux Studio website as well.
